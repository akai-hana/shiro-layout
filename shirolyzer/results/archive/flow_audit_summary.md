# Flow audit — cfgE Seiro【白】`aiojvlnrwhe;fpgytmbcquzkd,./`

Full categorized tables (all 551 bigrams, all 5,461 trigrams, top-199 and
top-996 words): `results/flow_audit.txt` (generated by `analysis/flow_audit.py`).

Fingering convention: **bigrams/trigrams use context-optimal fingering**
(the DP's chosen fingers from the BIG/TRI tables) — this is what the layout
actually charges. Trigram *patterns* (alternate/inroll/redirect/…) use the
**default-finger** classification for comparability with community tools.

## 1. Bigrams — category totals (all 551, corpus-weighted)

| category | % of bigram mass | note |
|---|---|---|
| alt (cross-hand) | **66.6%** | hand alternation; the layout's identity |
| leap (same-hand, FORDER gap ≥2) | **14.5%** | mostly pinky→index sweeps |
| roll_in | 12.1% | toward index (rewarded, W_ROLL_IN) |
| roll_out | 4.1% | away from index |
| repeat (double letter) | 2.8% | `ll`,`ss`,`ee`… fixed cost |
| **sfb** (same-finger, alt-rescued) | **0.02%** | the core promise holds |

Scissors (subset of rolls/leaps):
| pair | % | verdict |
|---|---|---|
| MR (middle↔ring) | **0.724%** | from `pa`,`cr`,`rc` — the worst scissor cluster |
| IM_hsb (index↔middle, adjacent) | 0.687% | from `po`,`op`,`cl`,`eq` — mild (1.5×) |
| RP (ring↔pinky) | 0.003% | negligible |

**Observation A — the leap bucket is the layout's one structural trade-off.**
`he` (3.54%), `be`, `of`, `by`, `for`, `but` are all left-hand pinky→index
sweeps (FORDER gap 3, e.g. `he` = A(LP)→F(LI)). These are *common English*
bigrams that land on a full lateral sweep of one hand. It's the direct price
of putting `h` on left-pinky-home `A` (a stated design choice) while `e` sits
on left-index `F`. The trigram context usually rescues the feel (see below),
but the bigram-level leap is unavoidable given the `h`/`e` placement.

| pattern | % | note |

| inroll | 31.3% | toward index |

| **redirect_weak** | **0.55%** | paid W_REDIRECT_WEAK=1.80 — the expensive one |

**Observation B — the 14.5% "sfb_tri" is mostly an illusion.** Decomposed:
- **unavoidable (double-letter) = 1.21%** — `all`,`ess`,`nce`,`inc`,`ill`:
  a repeated letter (`ll`,`ss`,`cc`) that no fingering can fix. This is the
  true floor of same-finger trigrams.
- **rescuable (different letters) = 1.47%** — but the context-optimal DP
  *already* resolves the biggest ones: `ion` (0.77%) → **MIM** (not MMM),
  `tio` (0.61%) → **IMI**, `hey` (0.14%) → **PMI**. The middle key breaks the
  same-finger run. So the *charged* sfb_tri cost is far below the raw 14.5%.

## 3. The genuine residual problems (ranked by cost)

1. **MR scissors — 0.72% of bigrams** (`pa`,`cr`,`rc`,`ap`). The single worst
   scissor cluster. `pa` (0.29%), `ap` (0.21%), `cr` (0.12%), `rc` (0.10%).
   These are middle↔ring with a row change — charged 6× (SCISSOR_MR_RP).
2. **redirect_weak — 0.55%** (`abo` 0.24% of trigrams, `pai`, `ifi`, `scr`,
   `phi`). The layout's expensive trigram (1.80). Small but the top cost per
   unit frequency.
3. **IM_hsb scissors — 0.69%** (`po`,`op`,`cl`,`eq`) — milder (1.5×), and
   `po`/`op` are partly the punctuation-adjacency the B6 punct variant targets.
4. **left pinky→index leaps — the `he`/`be`/`by` class** — structural, tied
   to `h` on `A`.

**Observation C — top-250 words are *better* than average on redirects**
(0.42% vs 0.55% weak-redirect). The words people type most have slightly
cleaner flow than the corpus tail. No word-frequency-driven redesign is
warranted — the commonest words are already the best-typing ones.

Notable clean top words: `with` (all-alt), `the` (alt-leap-inroll), `have`
(roll_in-alt-alt). Words carrying a rescuable sfb_tri: `they`,`only`,`feel`,
`look`,`good` — all of these have a double-letter or a context-rescued
same-finger pair (verified: `feel` = F/E/E/G contains `ee` repeat; `look`
contains `oo`).

## 5. Improvement assessment

The flow audit **confirms the D-series floor** but isolates where the *feel*
residual lives — none of it is a letter-swap fix (proven impossible):

| residual | size | fixable by swap? | realistic mitigation |
|---|---|---|---|
| MR scissors (`pa`,`cr`) | 0.72% | no (1-swap floor) | alt-finger the `a` (ring→middle is already the alt); B6 punct variant already relocates `p` |
| redirect_weak (`abo`) | 0.55% | no | trigram context; already at W=1.80, further weight changes were swept in A4 (no gain) |
| IM_hsb (`po`,`cl`) | 0.69% | no | mild 1.5×; `.`-on-Q punct variant (B6) crosses `s.` |
| `he`/`be`/`by` leaps | ~1.5% | no — tied to `h` on `A` | structural; the `h`-on-pinky-home is a design principle, not a defect |

**Bottom line:** the layout's flow is dominated by alternation (66%) and inroll
(31%), with SFBs at 0.02% and weak-redirects at 0.55%. The two real cost
clusters — MR scissors and the left pinky→index `he`/`be`/`by` leaps — are both
structural (locked by the `h`-on-pinky-home principle and the `a`/`p`/`c`/`r`
placement) and sit inside the machine-confirmed local optimum. **No improvement
is available**; this audit's value is documenting *where* the residual feel
cost concentrates so any future redesign (or the optional punct variant) can
target it knowingly.
